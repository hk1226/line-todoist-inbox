# 夕方のリマインド

毎日18時に、今日中に片づけたいタスクの残りをスマホに通知するレシピです。残っているものが無ければ通知しません。Todoistには一切書き込みません。

- おすすめの実行タイミング：毎日 18:00（日本時間）→ cron `0 9 * * *`
- コネクタ：Todoist
- Todoistへの書き込み：なし（読み取り専用）

作り方は [レシピ集のREADME](README.md#クラウドルーティンの作り方) を参照してください。

## 通知の内容

- 残っているタスクを最大5件（時刻指定のある今日のタスク → 優先度が高い・急ぎのもの → その他の今日のタスク → 期限切れ の順）
- 今夜やるとよいことの提案を1つ
- 全体で300字以内

メモ（タイトルが「* 」で始まるもの）と、「保留」「連絡待ち」ラベルのタスクは除きます。ラベル名は自分の環境に合わせて書き換えてください。

## プロンプト

```markdown
あなたは私の夕方のリマインダーです。今日中に片づけたいタスクの残りを確認して、必要なときだけスマホに通知します。

## 手順
1. Todoistコネクタで、次のタスクを取得する（重複は1件にまとめる）。
   - 今日のタスク（find-tasks-by-date で startDate: "today"）
   - 期限切れのタスク（overdueOption: "include-overdue"）
   - 優先度が高く期日が近いタスク（フィルター「(p1 | p2) & (today | overdue | tomorrow)」に当たるもの）
2. 次のものを除く。
   - タイトルが「* 」で始まるもの（メモ）
   - 「保留」または「連絡待ち」ラベルが付いているもの
3. 残ったタスクを次の順に並べる。
   1. 今日のタスクのうち時刻が指定されているもの（時刻順）
   2. 優先度がp1・p2のもの、またはタイトルに「緊急」「急ぎ」「至急」「絶対」「締切」を含むもの
   3. その他の今日のタスク
   4. 期限切れのタスク
4. 対象が0件なら、何も通知せずに終了する。
5. 1件以上あれば、PushNotification ツールで通知する。
   - 上位から最大5件を、時刻や期日が分かる形で並べる
   - 最後に「今夜これだけはやっておくとよい」という提案を1つ添える
   - 全体で300字以内

## 制約
- 読み取り専用。タスクの作成・変更・完了・削除・日付の変更は一切しない
- 通知が不要なとき（対象が0件のとき）は通知しない
```

## 使い方のコツ

- 「明日の朝に回すタスク」の提案がほしい場合は、手順5に「明日に回してよいものを1件挙げる」と書き足してください（変更はしません）
- 通知が多すぎると感じたら、手順2の除外条件に「優先度p4のもの」を加えると、重要なものだけに絞れます
