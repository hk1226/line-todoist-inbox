# AIルーティンのレシピ集

line-todoist-inbox 本体はAIを使わず、LINEから送ったものをTodoistのInboxに入れるだけです。このフォルダには、Inboxの整理や日々の通知をAIに任せたい人向けに、[Claude Code](https://claude.ai/code) のクラウドルーティンにそのまま貼り付けて使えるプロンプト例をまとめています。

どれも任意です。ボットはルーティンが無くても単体で動きます。

> 本プロジェクトは非公式であり、Todoist（Doist社）・LINE（LY Corporation）とは関係ありません。

## レシピ一覧

| レシピ | おすすめの実行タイミング | Todoistへの書き込み |
| --- | --- | --- |
| [Inbox自動整理](inbox-triage.md) | 1日3回（例：7時・12時・20時） | **あり**（Inboxのタスクの移動・ラベル・所要時間・コメント） |
| [朝のブリーフィング](morning-briefing.md) | 毎朝（例：7時） | なし（読み取り専用） |
| [夕方のリマインド](evening-reminder.md) | 毎日18時 | なし（読み取り専用） |
| [週次レビュー](weekly-review.md) | 毎週日曜21時 | なし（読み取り専用） |

## クラウドルーティンの作り方

クラウドルーティンは、決まった時刻にクラウド上でClaudeが動く定期実行エージェントです。パソコンの電源が切れていても動きます。

1. https://claude.ai/code/routines を開き、新しいルーティンを作成します
2. **コネクタ** に Todoist を追加します（初回はTodoistへのログインと連携の許可を求められます）
3. **プロンプト** に、各レシピのコードブロックの中身を貼り付けます。`{{...}}` で囲まれた部分は、あなたの環境に合わせて書き換えてください
4. **スケジュール** をcron形式で設定します。cronは **UTC（協定世界時）** で指定する点に注意してください。日本時間（JST）はUTC＋9時間なので、9時間引いた時刻を書きます

   | 日本時間 | cron（UTC） | 備考 |
   | --- | --- | --- |
   | 毎日 7:00 | `0 22 * * *` | UTCでは前日の22:00 |
   | 毎日 12:00 | `0 3 * * *` | |
   | 毎日 18:00 | `0 9 * * *` | |
   | 毎日 20:00 | `0 11 * * *` | |
   | 毎日 7:00・12:00・20:00 | `0 22,3,11 * * *` | Inbox自動整理の例 |
   | 毎週日曜 21:00 | `0 12 * * 0` | 日曜21時JSTはUTCでも日曜12時 |

5. 保存したら、一度手動で実行して結果を確認します

### スマホへの通知

ルーティンからは `PushNotification` ツールで、Claudeアプリ経由でスマホに通知を送れます。朝のブリーフィングなど「読むためのもの」は、通知で受け取るのが便利です。通知を受け取るには、スマホにClaudeアプリを入れて通知を許可しておいてください。

### 注意点

- ルーティンの実行は、Claudeのプランの利用枠を消費します。回数を増やしすぎないようにしてください
- **書き込みを許すのは Inbox自動整理 だけにすること** をおすすめします。ブリーフィング・リマインド・レビューは読み取り専用で作られています。プロンプトの「読み取り専用」の指示は消さないでください
- Inbox自動整理も、最初の数日は結果のコメント（「🤖整理: …」）を確認し、ルールを調整してから任せるのが安全です
- プロンプトは標準語で書いています。好みの口調（方言など）にしたい場合は、プロンプトの冒頭に「〇〇弁で報告する」などと書き足してください

## LINEボットとの連携ポイント

各レシピは、このボットがInboxに入れるタスクの形を前提にしています。

| ボットが作るもの | 形 | レシピ側での扱い |
| --- | --- | --- |
| メモ | タイトルが「* 」で始まる | メモとして扱い、タスクの集計から除く |
| 箇条書きの見出し | コメント「見出し：〇〇」 | 振り分けの手がかりにする |
| 写真だけのタスク | タイトル「📷 写真（日時）」、写真はコメントの添付 | 自動整理が写真を見てタイトルを付ける |
| 自動整理が迷ったタスク | コメント「🤖要確認: …」 | 自動整理はスキップし、朝のブリーフィングなどで人に知らせる |
