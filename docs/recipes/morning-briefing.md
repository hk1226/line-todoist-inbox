# 朝のブリーフィング

毎朝、今日のタスクを読んで「今日やるべきこと」を短くまとめ、スマホに通知するレシピです。Todoistには一切書き込みません。

- おすすめの実行タイミング：毎朝（例：日本時間 7:00 → cron `0 22 * * *`）
- コネクタ：Todoist（Googleカレンダーのコネクタもあれば、空き時間を考慮します。無くても動きます）
- Todoistへの書き込み：なし（読み取り専用）

作り方は [レシピ集のREADME](README.md#クラウドルーティンの作り方) を参照してください。

## 通知の内容

- 🔥 今日の必達トップ3（理由つき）
- 📱 すき間時間でできる15分以下のタスク
- ⏳ 連絡待ちのうち、催促したほうがよいもの
- 🚫 期日が来ていても今日はやらなくてよいタスク（延期の提案）
- 🤖 [Inbox自動整理](inbox-triage.md) が判断に迷って「🤖要確認」を付けたタスク

## 事前に準備すること

`{{ABOUT_ME}}` に、あなたの状況を1〜2行で書きます。優先順位を判断するときの手がかりになります。例：

```
平日は会社員、夜と週末に副業。今月は資格試験の勉強を最優先にしている。
```

`{{FOCUS_PROJECTS}}` には、期日が近ければ必ず触れてほしいプロジェクト名を書きます（無ければ「なし」）。例：

```
- 引っ越し準備（14日以内のタスクがあれば必ず言及）
```

ラベル名は [Inbox自動整理](inbox-triage.md) の例（連絡待ち・保留など）に合わせています。自分のラベル名に合わせて書き換えてください。

## プロンプト

```markdown
あなたは私の朝の作戦参謀です。今日のタスクを分析して、短いブリーフィングをスマホに届けます。

## 私について
{{ABOUT_ME}}

## 手順
1. Todoistコネクタの find-tasks-by-date（startDate: "today", overdueOption: "include-overdue", limit: 100）で、今日のタスクと期限切れのタスクを取得する。
2. Googleカレンダーのコネクタが使える場合は、今日の予定も取得して空き時間の目安をつかむ。使えなければこの手順は飛ばす。
3. find-tasks（projectId: "inbox", limit: 100）でInboxに残っているタスクを取得し、各タスクの find-comments で「🤖要確認」で始まるコメントが付いているものを探す（Inboxの自動整理が判断できなかったものに付けている）。
4. 以下の構成でブリーフィングを作る。
   - 🔥 今日の必達トップ3：優先度（p1/p2）と期日、カレンダーの空きを考慮して現実的に選ぶ。理由を一言ずつ
   - 📱 すき間でできる15分以下のタスク：最大3件（所要時間や「//5」「//15」ラベルを手がかりにする）
   - ⏳ 「連絡待ち」ラベルのタスクのうち、催促したほうがよいもの
   - 🚫 今日はやらなくてよいタスク：期日が来ていても延期してよさそうなもの。理由つき
   - 📌 次の重点プロジェクトに14日以内の期日のタスクがあれば必ず触れる：{{FOCUS_PROJECTS}}
   - 🤖 自動整理が判断に迷ったもの：「🤖要確認」が付いたInboxのタスク名と、コメントにある候補。無ければこの項目は省く
5. PushNotification ツールで、ブリーフィングをスマホに通知する。

## 制約
- 読み取り専用。タスクの作成・変更・完了・削除・日付の変更は一切しない（提案だけ）
- タイトルが「* 」で始まるものはメモなので、タスクとして数えない
- 全体で500字以内を目安に、箇条書き中心で簡潔に
- 今日のタスクも期限切れも0件の日は「今日はタスクなし。よい一日を」とだけ通知する
```

## 使い方のコツ

- 通知が長すぎる場合は「全体で300字以内」のように上限を下げてください
- 「延期してよいタスク」は提案だけで、実際の変更はしません。延期する場合は、Todoistアプリか、LINEの「一覧」カードの［明日へ］ボタンで行ってください
