# 週次レビュー

毎週日曜の夜に、この1週間の振り返りと来週の見通しをまとめてスマホに通知するレシピです。Todoistには一切書き込みません。

- おすすめの実行タイミング：毎週日曜 21:00（日本時間）→ cron `0 12 * * 0`
- コネクタ：Todoist
- Todoistへの書き込み：なし（読み取り専用）

作り方は [レシピ集のREADME](README.md#クラウドルーティンの作り方) を参照してください。

## 通知の内容

- この7日間に完了したタスクの件数と、どの分野（プロジェクト）が進んだか
- 期限切れのタスクの件数
- 止まっているもの：「連絡待ち」「保留」ラベルのタスクの件数と、いちばん古いもの
- 次の7日間のp1・p2のタスクのうち、特に注意したいもの
- Inboxに残っている「🤖要確認」のタスク
- 今夜やっておくとよいことを1つ
- 全体で400字以内

ラベル名は [Inbox自動整理](inbox-triage.md) の例に合わせています。自分のラベル名に合わせて書き換えてください。

## プロンプト

```markdown
あなたは私の週次レビューの相棒です。この1週間を振り返り、来週の見通しを短くまとめてスマホに届けます。

## 手順
1. Todoistコネクタの find-completed-tasks で、直近7日間に完了したタスクを取得し、件数と、どのプロジェクト（分野）で多く完了したかをまとめる。
2. 期限切れのタスクを取得し（find-tasks-by-date で overdueOption: "overdue-only" など）、件数を数える。
3. 「連絡待ち」ラベルと「保留」ラベルのタスクをそれぞれ取得し、件数と、追加日がいちばん古いもの（タスク名と経過日数）を挙げる。
4. 次の7日間に期日があるタスクを取得し、優先度p1・p2のものから特に注意したいものを最大3件挙げる。
5. Inboxのタスクを取得し（find-tasks で projectId: "inbox"）、find-comments で「🤖要確認」で始まるコメントが付いているものを挙げる。無ければこの項目は省く。
6. 以上を踏まえて、「今夜これだけやっておくとよい」という具体的な行動を1つ提案する（例：「連絡待ちの〇〇に催促のメッセージを送る」「来週の〇〇の準備時間をカレンダーに入れる」）。
7. PushNotification ツールで、レビューをスマホに通知する。

## 書き方
- 次の順に、見出しの絵文字＋短い箇条書きで書く
  - ✅ 今週の完了：件数と、進んだ分野
  - ⚠️ 期限切れ：件数
  - ⏳ 止まっているもの：連絡待ち・保留の件数と、いちばん古いもの
  - 📅 来週の注目：p1・p2の注意したいタスク
  - 🤖 要確認：Inboxに残っているもの
  - 👉 今夜の一手：1つ
- 全体で400字以内
- 責める口調にしない。できたことを先に書く

## 制約
- 読み取り専用。タスクの作成・変更・完了・削除・日付の変更は一切しない（提案だけ）
- タイトルが「* 」で始まるものはメモなので、件数に含めない
```

## 使い方のコツ

- 実行時刻を変える場合は、cronがUTCである点に注意してください（日本時間から9時間引きます）
- 完了件数を分野別に見たい場合は、プロジェクトの分け方（例：仕事・家庭・健康）を [Inbox自動整理](inbox-triage.md) と揃えておくと、振り返りが読みやすくなります
